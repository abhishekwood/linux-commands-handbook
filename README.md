# 🐧 Linux Commands Handbook

Welcome to the **Linux Commands Handbook**! This repository serves as a comprehensive reference guide for Linux commands, categorized by their specific use cases. Whether you are a beginner looking to navigate the terminal or an administrator managing system performance, you will find essential commands here.

## 📖 Table of Contents

### 1. Essentials
- **[Basic Commands](Basic-commands.md)**
  - Navigation (`cd`, `ls`, `pwd`)
  - File creation and manipulation (`touch`, `mkdir`, `cp`, `mv`)
  - Viewing file content (`cat`, `less`, `head`)

### 2. File Management & Permissions
- **[File Permissions](File_Permissions.md)**
  - Understanding Read, Write, and Execute modes
  - Changing permissions (`chmod`, `chown`, `chgrp`)
- **[File Compression](File-Compression.md)**
  - Archiving and compressing files (`tar`, `gzip`, `zip`)

### 3. System Administration
- **[System Information](System-information.md)**
  - Kernel and OS details (`uname`, `hostname`)
  - Hardware info (`lscpu`, `lsblk`, `free`)
- **[User Management](User_management.md)**
  - Creating and deleting users (`useradd`, `userdel`)
  - Group management (`groupadd`, `usermod`)
- **[Process Management](Process_Management.md)**
  - Monitoring processes (`ps`, `top`, `htop`)
  - Killing unresponsive tasks (`kill`, `pkill`)

### 4. Networking & Connectivity
- **[Networking](Networking.md)**
  - IP configuration (`ifconfig`, `ip`)
  - Connectivity checks (`ping`, `curl`, `wget`)
  - Network statistics (`netstat`, `ss`)
- **[SSH (Secure Shell)](SSH.md)**
  - Remote login (`ssh`)
  - Key management and secure transfers (`scp`)

### 5. Advanced Monitoring
- **[System Monitoring & Performance](System_monitring_performance.md)**
  - Real-time system resource usage
  - Disk usage analysis (`df`, `du`)

1. Click on any of the category links above to view the specific commands.
2. Each file contains command syntax, explanations, and common examples.
3. Use `Ctrl + F` inside any file to search for a specific command.
