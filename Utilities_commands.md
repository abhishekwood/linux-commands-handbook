-----------------------------------------
MISCELLANEOUS / UTILITIES COMMANDS (LINUX)
-----------------------------------------

1) echo  
   Use: Display message or variable content  
   Example:
     echo "Hello World"
     echo $PATH

2) date  
   Use: Show current date & time  
   Example:
     date
     date +"%Y-%m-%d %H:%M:%S"

3) cal  
   Use: Display calendar  
   Example:
     cal
     cal 2025

4) clear  
   Use: Clear terminal screen  
   Example:
     clear

5) history  
   Use: Show command history  
   Example:
     history
     history | grep "ssh"

6) alias  
   Use: Create shortcut for commands  
   Example:
     alias ll='ls -la'
     unalias ll

7) uname  
   Use: Display system information  
   Example:
     uname -a

8) sleep  
   Use: Pause execution for a certain time  
   Example:
     sleep 5   # wait 5 seconds

9) date  
   Use: Show date and time in custom format  
   Example:
     date +"%d-%m-%Y %H:%M:%S"

10) man  
    Use: Show manual/help for commands  
    Example:
      man ls
      man chmod

11) file  
    Use: Show file type  
    Example:
      file script.sh
      file image.png

12) clear  
    Use: Clear terminal screen  
    Example:
      clear

13) uptime  
    Use: Show system uptime and load  
    Example:
      uptime

14) who  
    Use: Show logged in users  
    Example:
      who

15) ping  
    Use: Check connectivity to a host  
    Example:
      ping google.com
      ping -c 4 google.com

16) bc  
    Use: Command-line calculator  
    Example:
      bc
      echo "5+3" | bc

17) tee  
    Use: Write output to file and stdout simultaneously  
    Example:
      echo "Hello" | tee file.txt
