-----------------------------------------
SYSTEM INFORMATION COMMANDS (LINUX)
-----------------------------------------

1) uname  
   Use: System ka kernel & OS info dekhne ke liye  
   Example:
     uname
     uname -a

2) hostname  
   Use: System ka hostname dekhna ya set karna  
   Example:
     hostname
     hostnamectl set-hostname mypc

3) uptime  
   Use: System kitni der se ON hai + load average  
   Example:
     uptime

4) date  
   Use: Current date & time dekhne ke liye  
   Example:
     date

5) whoami  
   Use: Current user ka naam show karta hai  
   Example:
     whoami

6) who  
   Use: System me kaun logged in hai  
   Example:
     who

7) which  
   Use: Command ka install path dikhata hai  
   Example:
     which python
     which bash

8) id  
   Use: User ID, group ID aur permissions dekhne ke liye  
   Example:
     id
     id username

9) lsb_release  
   Use: Linux distribution ka version information  
   Example:
     lsb_release -a

10) arch  
    Use: System architecture (x86_64 / arm64) check karne ke liye  
    Example:
      arch

11) neofetch  
    Use: Stylish system info (agar installed ho)  
    Example:
      neofetch

12) lscpu  
    Use: CPU ka full detail — cores, threads, model, speed  
    Example:
      lscpu

13) lsblk  
    Use: Block devices (disk/partitions) dekhne ke liye  
    Example:
      lsblk

14) free  
    Use: RAM usage dekhne ke liye  
    Example:
      free -h

15) df  
    Use: Disk usage check karne ke liye  
    Example:
      df -h

16) vmstat  
    Use: Memory, process, CPU performance status  
    Example:
      vmstat

17) dmidecode  
    Use: Hardware level system information  
    Example:
      sudo dmidecode
